# Mobilism Search CLI

A command-line tool for searching and downloading from Mobilism forums.

## Features

- Search Mobilism forums for topics
- Extract download links from various file hosts
- Automatic login handling
- Configurable through simple setup process

## Supported File Hosts

- uploadrar.com
- sendit.cloud
- rapidgator.net / rg.to
- filedot.to
- dropgalaxy.vip
- devuploads.com
- novafile.org / nfile.cc
- uploady.io
- katfile.com
- upfiles.com
- filefactory.com
- uploda.sh
